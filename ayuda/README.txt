Carpeta de ayuda rápida para cada método.

Aquí puedes crear archivos de texto como:
  - biseccion.txt
  - newton_raphson.txt
  - secante.txt
  - montante.txt
  - etc.

Cada archivo debe contener:
  - Nombre del método
  - Descripción breve
  - Fórmulas importantes
  - Sugerencias o tips para resolver los problemas

Estos textos se pueden vincular desde la interfaz con un botón de información (ℹ️).
